# Fusion2Free 实验方法与数据集

## 数据集描述

### 数据来源

本实验使用的 CAD 模型数据集来自 Fusion 360 平台导出的参数化设计文件。数据集按批次组织，存储于 `data/cad_json_repair/` 目录下，共包含 27 个子目录（编号 0000-0026）。

### 数据格式

- **原始格式**: Fusion 360 JSON 格式
  - 包含完整的参数化设计历史
  - 记录了草图、拉伸、布尔运算等操作序列
  - 每个特征包含几何信息和拓扑关系

- **转换格式**: FreeCAD Python 脚本
  - 通过 `fusion2free.py` 转换引擎生成
  - 可直接由 FreeCADCmd 执行重建 3D 模型

## 实验平台

### 被测 FreeCAD 版本

| 版本标识 | 版本号    | Git 版本 | 类型                |
| -------- | --------- | -------- | ------------------- |
| **FC1**  | 0.22.0dev | R38854   | IREP 项目定制构建版 |

### 实验环境

- **操作系统**: Windows
- **FreeCAD 执行方式**: FreeCADCmd.exe（命令行模式）
- **超时设置**: 单模型运行限制 60 秒

## 实验：参数化梯度测试

### 实验目的

测试 FreeCAD ，验证特征参数在不同缩放级别下重生成的结果。

### 测试框架

使用 `batch_gradient_test.bat` 进行批量梯度测试。

### 梯度设置

对每个模型的选定特征执行 5 种梯度的参数缩放：

| 梯度名称        | 缩放因子 | 描述                      |
| --------------- | -------- | ------------------------- |
| large_reduction | 0.25×    | 大幅缩小至原始尺寸的 25%  |
| small_reduction | 0.60×    | 小幅缩小至原始尺寸的 60%  |
| tiny_adjust     | 1.02×    | 微调至原始尺寸的 102%     |
| small_increase  | 1.50×    | 小幅增大至原始尺寸的 150% |
| large_increase  | 2.50×    | 大幅增大至原始尺寸的 250% |

### 特征选择方法

1. **扫描阶段**: 执行 `test_model.py` 的 SCAN 模式
   - 识别模型中的所有 `PartDesign::Pad` 特征
   - 随机选择一个特征（排除第一个特征，避免基准特征）
   - 记录特征索引和原始长度

2. **测试阶段**: 对选定特征依次应用 5 种梯度

### 成功/失败判定

在特征重建过程中，每个特征可能产生两种结果：

**失败特征**:

- 判定条件: 输出包含 `"criteria X failed"`
- 记录: 失败计数 +1

**成功特征**:

- 判定条件: 输出包含 `"Fast Regeneration"` 且无失败标记
- 记录:
  - 成功计数 +1
  - 提取 6 个时间指标

### 时间指标提取

对每个成功重建的特征，提取以下时间统计（单位：毫秒）：

| 指标名称          | 描述                           |
| ----------------- | ------------------------------ |
| Criteria 1        | 标准 1 检查耗时                |
| Criteria 2        | 标准 2 检查耗时                |
| Sewing Algorithm  | 缝合算法耗时                   |
| Fast Regeneration | 快速再生总耗时                 |
| GBR               | 普通算法总耗时                 |
| Time Ratio        | GBR / Fast Regeneration 时间比 |

### 输出文件

每个梯度测试输出：

- `test.log` - 完整运行日志
- `{model_name}_{gradient_name}.step` - 修改后导出的 STEP 几何文件

## 实验二：优秀案例筛选

### 筛选标准

将满足以下条件的模型标记为"优秀案例"（Excellent）：

- 任意梯度的测试日志中存在 **Time Ratio > 5**
- 表明快速再生算法相比普通算法有 5 倍以上的性能提升

### 筛选结果

优秀案例模型会被自动复制到 `excellent/` 目录，包含：

- 原始 Python 模型文件
- 所有梯度的测试日志
- 导出的 STEP 文件

## 数据统计与分析

对于每一个模型的每一个梯度的log，我需要分析有多少成功了，多少失败了，而对于成功的那些，我需要统计6个指标各自的平均值，这样每个模型列的csv表格中将有若干行8列。然后在所有模型的汇总表格中，每个模型一行，记录这8个属性各自的平均值。

### 单模型 CSV 输出

每个模型生成独立 CSV 文件，包含 9 列：

| 列名           | 描述             |
| -------------- | ---------------- |
| gradient_name  | 梯度名称         |
| success_count  | 成功特征数       |
| fail_count     | 失败特征数       |
| criteria1_avg  | 标准 1 平均耗时  |
| criteria2_avg  | 标准 2 平均耗时  |
| sewing_avg     | 缝合算法平均耗时 |
| fast_regen_avg | 快速再生平均耗时 |
| gbr_avg        | GBR 平均耗时     |
| ratio_avg      | 平均时间比       |

### 汇总 CSV 输出

所有模型生成汇总 CSV，包含 9 列：

| 列名           | 描述                             |
| -------------- | -------------------------------- |
| model_name     | 模型名称                         |
| total_success  | 总成功特征数（所有梯度）         |
| total_fail     | 总失败特征数（所有梯度）         |
| criteria1_avg  | 标准 1 平均耗时（所有梯度平均）  |
| criteria2_avg  | 标准 2 平均耗时（所有梯度平均）  |
| sewing_avg     | 缝合算法平均耗时（所有梯度平均） |
| fast_regen_avg | 快速再生平均耗时（所有梯度平均） |
| gbr_avg        | GBR 平均耗时（所有梯度平均）     |
| ratio_avg      | 平均时间比（所有梯度平均）       |

```
        ├── {model1}/
        └── {model2}/
```
